04Testing & quality

Software that works
when it has to.

Testing is not the last step of my projects. On PSAUx I worked as tester as well as team lead and developer, and PulseHear had to be dependable before it could be useful — an alert that is missed is worse than no alert at all.

Test design

Black-box & white-box

Derive cases from the requirements and from the code path, so both what the user does and what the function does are covered.

JUnit

Unit testing

Write unit tests against application logic to catch regressions while the code is still changing.

Katalon Studio

Automated UI testing

Build repeatable UI test suites so every build is checked the same way instead of by hand.

Code quality

Analysis & review

Run code quality analysis alongside manual testing, with issues tracked through Jira.
